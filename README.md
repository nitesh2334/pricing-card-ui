# 💳 Pricing Card UI

Modern responsive pricing cards built with HTML, CSS, and JavaScript.

## 🚀 Features
- 3 pricing tiers (Basic, Pro, Premium)
- Highlighted "Most Popular" plan
- Responsive design
- Hover animations
- Interactive button states

## 🛠 Tech Stack
- HTML
- CSS (Flexbox, gradients, animations)
- JavaScript (basic interactivity)
